# MeowTV Show Gallery

A simple web app that lets you search for TV shows and see the results as cards.

## What it does

- Search for a TV show by name
- Shows up to 10 matching results as cards
- Each card shows the show name, summary, premiere date, last updated date, genres, rating, and main cast
- Shows a message if the search is empty, has no results, or fails

## Built with

- HTML
- CSS (Flexbox)
- JavaScript (Fetch API)
